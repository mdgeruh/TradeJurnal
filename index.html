                                        Tampilan

                                        Pilih mode, skema warna, warna aksen, dan pasangan warna untung/rugi. Tersimpan di browser ini, tidak ikut ekspor JSON; cetak Laporan tetap memakai tema terang.
                                        ModeOtomatis mengikuti pengaturan perangkat.
                                        Warna aksenMenimpa warna utama skema (tombol utama, tab aktif, garis kurva) untuk mode yang sedang dipakai. Ditolak bila kontras terhadap latar < 4,5:1.
                                        Warna untung/rugiBiru/oranye untuk yang sulit membedakan hijau–merah. Tidak terpengaruh warna aksen.
                                        Kembali ke bawaanMode Gelap, skema Emas Klasik, tanpa aksen custom dan tanpa mode buta warna.

                                        Batas harian

                                        Batas pribadi untuk analisis overtrading di tab Laporan. Kosongkan untuk menonaktifkan. Tersimpan di browser ini (localStorage), tidak ikut ekspor JSON.
                                        Maks rugi harian (¢) Hari dianggap melewati batas bila rugi kumulatif hari itu (urut waktu tutup) mencapai nilai ini.
                                        Maks transaksi per hari Transaksi ke-(N+1) dan seterusnya pada hari yang sama dihitung melewati batas.

                                        Ekspor data

                                        Simpan salinan jurnal ini sebagai cadangan (backup) dari data yang sedang aktif di browser ini.
                                        Salinan dashboard (.html) Halaman + data saat ini. Karena kode kini terpisah, simpan di folder yang sama dengan style.css, app.js, sync.js, dan config.js. Untuk cadangan, JSON lebih praktis.
                                        Data mentah (.json) Hanya data transaksi & ringkasannya, untuk dianalisis di tempat lain atau diedit lalu diimpor kembali.

                                        Impor data

                                        Muat file data (.json) baru — hasil ekspor dari dashboard ini atau format yang sama. Data tersimpan otomatis di penyimpanan lokal browser ini (localStorage), jadi tetap ada walau tab ditutup atau halaman dimuat ulang — tanpa perlu download file HTML baru tiap kali.
                                        Pilih file JSON Dashboard akan memuat ulang dengan data dari file yang dipilih, tersimpan di browser ini.
                                        Hapus data tersimpan Kembali ke data bawaan file HTML ini (data yang terakhir diimpor di browser ini akan dihapus). Cadangan JSON otomatis didownload dulu sebelum dihapus.
