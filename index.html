                            Ekspor data

                            Simpan salinan jurnal ini sebagai cadangan (backup) dari data yang sedang aktif di browser ini.
                            Salinan dashboard (.html) Halaman + data saat ini. Karena kode kini terpisah, simpan di folder yang sama dengan style.css, app.js, sync.js, dan config.js. Untuk cadangan, JSON lebih praktis.
                            Data mentah (.json) Hanya data transaksi & ringkasannya, untuk dianalisis di tempat lain atau diedit lalu diimpor kembali.

                            Impor data

                            Muat file data (.json) baru — hasil ekspor dari dashboard ini atau format yang sama. Data tersimpan otomatis di penyimpanan lokal browser ini (localStorage), jadi tetap ada walau tab ditutup atau halaman dimuat ulang — tanpa perlu download file HTML baru tiap kali.
                            Pilih file JSON Dashboard akan memuat ulang dengan data dari file yang dipilih, tersimpan di browser ini.
                            Hapus data tersimpan Kembali ke data bawaan file HTML ini (data yang terakhir diimpor di browser ini akan dihapus). Cadangan JSON otomatis didownload dulu sebelum dihapus.
