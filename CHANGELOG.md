Perubahan Jurnal XAUUSD, terbaru di atas. Semua rilis 22 Sep – 1 Okt 2026. Versi berbahasa pengguna akhir ada di aplikasi (Setelan → Tentang aplikasi). v1.1.122 ke atas dicatat per versi; v1.0.0–v1.1.121 diringkas per tema. Status & todo: `SUMMARY.md`.

## Rilis terbaru
### 1.1.145 — 1 Okt
- **Setelan P2: parameter kalkulator:** section baru `#calcParamSection` "Kalkulator lot" (kelompok Trading) dengan isian `#cpPipval` (nilai pip per 1 lot, ¢), `#cpRisk` (%), `#cpSl` (pips), `#cpRr` (×), tombol **Bawaan** (isi `CALC_DEFAULTS`, belum disimpan) dan **Simpan**. Nilai ditulis ke `DATA.dashboard.mm` (`pipval`, `risk` sebagai pecahan, `sl`, `tp_pips` = sl × rr) lalu `saveActiveData(DATA)`; ikut ekspor JSON/HTML mandiri, **tidak** ikut sinkron Supabase (tabel `pengaturan` hanya `kurs`). Tanpa reload: kalkulator membaca `calcParams()` tiap render, `window.applyCalcDefaults()` mengisi ulang input modal. Validasi: pip > 0, risiko 0,1–100%, SL ≥ 1, R:R ≥ 0,1; risiko > 3% disimpan dengan peringatan. "Ukuran kontrak" sengaja tidak dibuat isian terpisah: satu-satunya pemakaiannya adalah rumus lot (`risiko / (SL × pipval)`), dan nilai pip per lot sudah mencakupnya.
- **Perbaikan:** `calcParams()` memberi nilai aman bila field `mm` kosong/0. Sebelumnya file baru (`tp_pips` 0) membuat R:R bawaan 0 (diklem 0,01); kini 1,5.
- **Setelan P2 (data & privasi, sebagian): mode sembunyi angka default:** Preferensi → "Angka PNL saat dibuka" (chip Tampil/Tersembunyi, `#prefHide`), kunci `jurnalHideNum` (`'1'`/`'0'`, masuk `SETTINGS_VALIDATORS` sehingga ikut ekspor/impor pengaturan). Handler tombol mata dijadikan `setPnlHidden(hidden)` (juga `window.setPnlHidden`), dipanggil saat muat dengan nilai kunci itu dan langsung saat chip diubah. Yang disamarkan sama dengan tombol mata (`.pnl-snapshot.hidden-values`); saldo hero tidak.
- **Diuji Playwright** (Chromium 390/1280px, 160 transaksi sintetis + data kosong, 31 cek): default kalkulator 1% / 150 / 1,5; simpan 20¢ / 2% / 100 / 2 → input kalkulator ikut berubah dan lot = saldo × 2% / (100 × 20); risiko 0 ditolak; bertahan setelah reload; mode tersembunyi berlaku langsung dan saat muat, tombol mata tetap membuka; validator; data kosong R:R 1,5; tanpa luapan horizontal dan tanpa error halaman. Belum diuji di perangkat asli dan mode terang.
- `APP_VERSION` → 1.1.145, `USER_CHANGELOG` entri baru 2026-10-01, `sw.js`: `CACHE` → `jurnal-v1.1.145`.
